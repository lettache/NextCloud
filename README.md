# NextCloud
Pet-проект #1

Цель проекта:

Перенос медиа данных из Яндекс диска в объектное хранилище S3 облачной платформы cloud.ru с сервисом NextCloud.

Используемые инструменты:

- VMware Workstation Pro v25.0.0.24995812
- OS Ubuntu 26.04 (на обоих хостах)
- WSL 2 Ubntu 24.04
- Ansible v2.21.6
- OpenTofu v1.13.9
- AWS CLI v2.41.1
- Docker v29.10.0

Шаги проекта:

- Подготовка и развёртывание на рабочей машине сервиса
- Миграция сервиса на домашнюю площадку через IaC с восстановлением из бэкапа и публикацией сервиса по HTTPS
- Документирование шагов проекта

## Результаты и метрики
- **Автоматизация:** Полное развертывание стека (Docker, Nextcloud, PostgreSQL, Redis, Nginx, S3-маунт) из состояния чистой ОС выполняется одной командой `ansible-playbook`.
- **Идемпотентность:** Повторный запуск плейбука завершается со статусом `failed=0`, внося только необходимые изменения.
- **Время восстановления (RTO):** Развертывание с нуля занимает 7 минут.
- **Статус:** Сервис успешно отвечает на запросы (HTTP 302 -> /login), внешнее S3-хранилище подключено и функционирует.
