# NextCloud
Pet-проект #1

Цель проекта:

Перенос медиа данных из Яндекс диска в объектное хранилище S3 облачной платформы cloud.ru с сервисом NextCloud.

Используемые инструменты:

- VMware Workstation Pro
- OS Ubuntu 26.04 (на обоих хостах)
- WSL2
- Docker
- Ansible

Шаги проекта:

- Подготовка и развёртывание на рабочем машине сервиса
- Миграция сервиса на домашнюю площадку через IaC с восстановлением из бэкапа и выбросом наружу
- Документирование шагов проекта
