# NextCloud
Pet-проект #1

Цель проекта:

Перенос медиа данных из Яндекс диска в объектное хранилище S3 облачной платформы cloud.ru с сервисом NextCloud.

Используемые инструменты:

- VMware Workstation Pro v25.0.0.24995812
- OS Ubuntu 26.04 (на обоих хостах)
- WSL 2 Ubntu 24.04
- Ansible v2.21.6
- OpenTofu v1.13.9
- AWS CLI v2.41.1

Шаги проекта:

- Подготовка и развёртывание на рабочей машине сервиса
- Миграция сервиса на домашнюю площадку через IaC с восстановлением из бэкапа и публикацией сервиса по HTTPS
- Документирование шагов проекта
